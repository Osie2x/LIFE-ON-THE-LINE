2Your Chapter 14 anti-trap framework

VOCABULARY ANCHORPrice taker; P = MR = AR.

Lock the first words: "A competitive firm takes the market price as given." If a question says "additional revenue from the next unit," hear MR, and for this chapter MR equals price.

MARGINAL REASONINGQuantity comes from MR = MC.

Do not choose Q by total cost or ATC. First find the margin: if MR > MC, make one more; if MR < MC, back up.

COORDINATE MAPPINGIntersection → Q-axis → P/ATC-axis.

Profit box = (P - ATC) × Q. You must extract all three numbers from the exact same quantity.

BOTH-WAYS RULESShutdown vs stay; exit vs enter.

Short run: shut if P < AVC, stay if P ≥ AVC. Long run: exit if P < ATC, enter if P > ATC.

DIRECTION CHECKMarket price rises → firm supplies more.

A competitive firm follows the price line. Higher P means the horizontal MR line moves up and intersects MC at a larger Q.

NO BLANKSEliminate one, then guess.

If a graph freezes you: find MR=MC first. If still stuck, remove one impossible choice and guess. Blank answers are guaranteed zero.
